## ✨ About SUMITX

SUMITX is an Android music application designed around a simple idea: make discovering, playing, and managing music feel seamless.

Explore music, enjoy a dedicated player experience, follow lyrics, organise your library, and save tracks for offline listening — all from one app.

## 🚀 Highlights

- **Music discovery** — explore and search for music.
- **A dedicated music player** — enjoy playback with a rich player interface and queue controls.
- **Lyrics experience** — view lyrics, including synchronised lyrics when available.
- **Your music library** — access local music, favourites, playlists, and listening history.
- **Offline downloads** — save supported tracks to your device for offline listening.
- **Music widgets** — control playback from your home screen.
- **Background playback** — keep listening while using other apps.
- **Library organisation** — edit audio tags and manage downloaded music.
- **Automatic updates** — check and install releases published on GitHub.

*Availability of online content, lyrics, and downloads can depend on the source, region, network, and the rights applicable to that content.*

## 📥 Download & Install

1. Open the **[latest SUMITX release](https://github.com/subhu1895991/SubHuMusic/releases/latest)**.
2. Download **SUMITX-Android.apk** from the Assets section.
3. Open the downloaded APK on your Android device.
4. If Android asks, allow your browser or file manager to install apps from that source.
5. Follow the installation prompts and open SUMITX.

## 🛠 Built With

SUMITX is developed for Android using:

- **Kotlin & Java**
- **Jetpack Compose** and Android UI components
- **AndroidX / Material components**
- **Media3 (ExoPlayer)** for media playback
- **Room** for local data storage
- **Glide & Coil** for artwork and image loading
- **NewPipe Extractor** for supported stream extraction
- **JAudioTagger** for audio metadata and artwork tagging
- **Gradle** and **GitHub Actions** for building and releasing
